# BAS Insights


## Description

BAS Insights is a full-stack analytics platform developed in collaboration with BAS World. The application provides insights into company growth, sales performance, and geographic distribution of transactions, as well as employee-related sales data.

Due to confidentiality restrictions, the official BAS World API could not be used. To solve this, a custom mocked API was developed to simulate realistic business data and enable full feature development.

The system also includes AI-powered insights and recommendations using the OpenAI API, along with an interactive chatbot that explains each recommendation in more detail.

This project was developed as a group assignment, where I acted as the Scrum Master and was responsible for facilitating the agile process and integrating the AI functionality.


## Features

- Interactive dashboards for sales and growth analytics  
- Country-based sales visualization  
- Employee performance tracking  
- Mocked API for realistic data simulation  
- AI-generated insights and recommendations  
- Chatbot per recommendation (OpenAI integration)  
- Filtering and data exploration tools  


## Tech Stack

- Frontend: React + TypeScript  
- Backend: Java Spring Boot  
- Database: PostgreSQL  
- API: Mocked REST API  
- AI Integration: OpenAI API  
- Architecture: Full-stack (separated frontend and backend services)  



## Usage

- View dashboards showing company growth and sales trends  
- Analyze sales per country and employee  
- Explore AI-generated recommendations  
- Interact with the chatbot for deeper insights
